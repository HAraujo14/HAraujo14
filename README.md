### [aws-etl-pipeline-terraform](https://github.com/HAraujo14/aws-etl-pipeline-terraform)

FinOps analytics with dbt + DuckDB: models AWS and GCP billing data into a conformed multi-cloud cost table and marts for daily cost, cost per team, month-over-month and unit cost, plus cost-spike anomaly detection and a simple forecast. Linted, tested and built in CI.
